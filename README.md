# CineList – Movie Watchlist Manager

## Project Description
CineList is a Movie Watchlist Manager built using the MERN stack (MongoDB, Express.js, React.js, and Node.js). It allows users to organize movies, track their watching status, filter and search movies, and manage ratings.

## Technologies Used
- **Frontend:** React.js, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **ODM:** Mongoose

## Features
- Add, view, edit, and delete movies
- Search movies by title
- Filter movies by genre and status
- Track movie watching status
- Assign priority and ratings
- Generate movie codes
- Paginate movie lists

## Project Structure
- `frontend/` – React user interface
- `backend/` – Express API and MongoDB integration

## Setup Instructions

### Backend
1. Open a terminal in the `backend` folder.
2. Run `npm install`.
3. Configure the required environment variables in `.env`.
4. Start the backend using the start command specified in `backend/package.json`.

### Frontend
1. Open another terminal in the `frontend` folder.
2. Run `npm install`.
3. Start the frontend using `npm run dev`.
