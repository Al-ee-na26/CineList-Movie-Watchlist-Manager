# CineList — Movie Watchlist Manager

A responsive MERN application for tracking movies you want to watch, are watching, and have watched.

## Requirements
- Node.js 18+
- MongoDB Atlas connection string
- npm

## Setup

### 1. Backend
```bash
cd backend
npm install
```
Open `backend/.env` and replace `MONGODB_URI` with your MongoDB Atlas connection string. For Atlas, create a database user and allow your current IP in Network Access. Use an exam-only database credential.

```bash
npm run dev
```
Backend runs at `http://localhost:5000`.

### 2. Frontend (new terminal)
```bash
cd frontend
npm install
npm run dev
```
Open the local URL printed by Vite (usually `http://localhost:5173`).

## API list

All responses use `{ "success": boolean, "message": string, "data": any }`.

| Method | Endpoint | Purpose |
|---|---|---|
| POST | `/api/movies` | Add movie; server generates yearly movie code |
| GET | `/api/movies?page=1&status=To%20Watch&genre=Action&search=star` | Filter, search, paginate (6 per page) |
| GET | `/api/movies/watch-next` | Highest priority To Watch movie; shortest runtime breaks ties |
| GET | `/api/movies/stats` | Status counts, hours watched, average rating, top watched genre |
| PUT | `/api/movies/:id` | Edit title, genre, runtime, platform, priority |
| PATCH | `/api/movies/:id/status` | Change status; requires rating when setting Watched |
| PATCH | `/api/movies/:id/rating` | Edit rating for a Watched movie |
| DELETE | `/api/movies/:id` | Delete unless status is Watching |
| GET | `/api/health` | Health check |

## Rules implemented
- Release year 1950 through current year; runtime 30–300 minutes, validated by client and server.
- Movie code is generated by the backend as `MV-<year>-<3-digit sequence>`, with counters per release year.
- New movies start as `To Watch`.
- Status transitions are restricted on the backend.
- Watched status requires a rating from 1 to 10 and automatically records watched date.
- Duplicate title/year is rejected case-insensitively with HTTP 409.
- Backend supports filters, title search, and six-item pagination.
- Watch Next chooses highest priority, then shortest runtime.
- Statistics are calculated on the backend.
- Watching movies cannot be deleted.
